About EventKit

Zero-database event registration & ticket management toolkit

v1.0.0

EventKit (@nsaky/eventkit) is a lightweight, zero-database Node.js toolkit for event registration, digital ticketing, QR code generation, ticket validation, attendee check-in, attendance analytics, search, and data export.

Package Information

  • npm Package: npmjs.com/package/@nsaky/eventkit
  • Package Repository: github.com/nsaky/eventkit.git
  • Demonstration Repository: github.com/nsaky/eventkit-demo.git
  • Engine Requirements: Node.js >= 22.0.0
  • Module System: CommonJS
  • Storage: Persistent JSON file storage with atomic temporary file renaming and async mutex protection

Features Demonstrated in this Application

1. Event Lifecycle

createEvent, getEvent, getAllEvents, updateEvent, and deleteEvent with cascading cleanup.

2. Attendee Registration

registerAttendee with email normalization, duplicate prevention, and capacity enforcement.

3. Automatic Digital Ticketing

generateTicket and retrieval via getTicket, getAllTickets, and getTickets.

4. Scannable QR Codes

generateQRCode in PNG Buffer and SVG vector formats encoding non-PII ticket references.

5. Non-Destructive Validation

validateTicket verifying validity, cancellation, wrong event, or prior check-in without mutating data.

6. Arrival Check-In Gate

checkIn and getCheckInStatus with duplicate arrival prevention and atomic batch persistence.

7. Ticket Cancellation

cancelTicket with state transition to CANCELLED and prevention of check-in.

8. Attendance Analytics

getAttendanceStats with live calculation of headcounts, attendance %, and capacity fill.

9. Roster Search

searchAttendees and searchTicket matching by name, email, or ticket ID.

10. Data Export

exportAttendees and exportEvent with RFC 4180 CSV escaping and JSON snapshots.
